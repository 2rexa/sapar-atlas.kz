# Sapar Atlas

Трёхъязычный туристический атлас Казахстана. Карта и вкладка «Маршруты» открывают 1 043 записи национального портала Kazakhstan.travel по 20 регионам и городам. Фотографии исходного атласа, справочная инфраструктура, маршруты и прогноз сохранены.

## Распаковка и запуск

Распакуйте три ZIP-архива в одну пустую папку с объединением папок `dist`. Архивы содержат разные файлы, перезаписывать их не потребуется.

1. `sapar-atlas-roundtrip-01-app.zip` — HTML, CSS, логика интерфейса и помощника, переводы, локальный сервер и эта инструкция.
2. `sapar-atlas-roundtrip-02-data.zip` — достопримечательности, тарифы и ссылки на источники, базовые маршруты, диапазоны расходов, отели, названия, авторы и ссылки на реальные съёмки.
3. `sapar-atlas-roundtrip-03-media.zip` — изображения, локальные видео, шрифт и его лицензия.

Откройте `dist/index.html` или запустите из общей папки `node serve.mjs` и откройте http://127.0.0.1:4173/. Зависимости npm не требуются.

## Что редактировать

- `dist/app.js` — маршруты приложения, карта, планировщик и сохранение.
- `dist/travel.js` — региональный каталог, карточки достопримечательностей, внешние видео и цены отелей.
- `dist/locales.js` и `dist/travel-data.js` — переводы интерфейса. В `travel-data.js` также редактируются `HOTEL_RATES` и `ROUTE_PRICES`.
- `dist/explore.js` и `dist/explore.css` — выбор старта, фильтры мест, сравнение готовых маршрутов и темы.
- `dist/explore-data.js` — перевод типов мест, краткие справки, города старта и ссылки на отдельные фото.
- `dist/road.js` и `dist/round-data.js` — дорожный расчёт, опубликованные билеты и тарифы природных территорий.
- `dist/assistant.js` — помощник по данным атласа.
- `dist/videos.js` — соответствия идентификаторов достопримечательностей записям `{url, title, author}`. Используйте идентификатор из `attractions.js` и прямую ссылку на оригинальный ролик YouTube или Rutube.
- `dist/attractions.js` — снимок каталога. Выполните `node refresh-attractions.mjs`, чтобы повторно получить названия, категории, населённые пункты, координаты, ссылки на фото и опубликованные часы из открытого каталога. В карточках большинства мест используются фото национального портала; для озера Камыстыбас указан автор фотографии Wikimedia Commons. Карточки содержат короткие справки по типу и местоположению, а у ключевых мест есть отдельные описания.
- `dist/data.js` — базовый каталог направлений, маршруты, геометрия и точки OpenStreetMap.
- `dist/media/` — медиа. Авторство и лицензии указаны в разделе «Источники».

## Источники и расчёты

- Достопримечательности: [Kazakhstan.travel](https://kazakhstan.travel/ru/regions). Импорт использует публичный список, который портал загружает для своих региональных страниц. В карточках есть ссылка на оригинал. При отсутствии перевода показывается исходное название.
- Отели: 23 тарифа по 20 регионам и городам. Используются сайты отелей, туроператоров и справочники. Ссылки стоят у каждой цены. Сумма за несколько ночей считается по опубликованному тарифу. Ссылка «Проверить цены на даты» передаёт регион и даты в поиск Booking.com.
- Точка старта — город, геолокация или выбранное место. Кнопка расчёта отправляет координаты в [OSRM / FOSSGIS](https://routing.openstreetmap.de/about.html). Дорога туда и обратно считается отдельно по сети OpenStreetMap, для машины или пешком, без учёта пробок. Ставка машины по умолчанию 50 ₸/км, её можно изменить. Для готового маршрута дорога добавляется к программе. Для места полная оценка доступна, когда известна опубликованная цена входа.
- Билеты и сборы указаны на одного взрослого. Для природных территорий базовые ставки из приказа № 232 пересчитаны по МРП 2026 года. При поездке на машине в оценку входит известный сбор за одну легковую машину. Дополнительные услуги, парковки, разрешения и платные дороги сверяются отдельно. Справа от цены есть ссылка на источник.
- Помощник в боковом меню использует карточки атласа, опубликованные цены и уже рассчитанные дороги. Он не требует регистрации. В исходниках есть опциональный серверный обработчик GPT‑6.2 Astra в `assistant-api.mjs`. Для его работы требуется подтверждённый ключ OpenAI в локальной среде. После настройки запускайте сервер командой `node --env-file=.env.local serve.mjs`. Публичная статическая версия отвечает по атласу.
- Маршруты: нижняя и верхняя оценка на одного человека. Смета включает указанные на странице билеты, еду, транспорт, ночлег и резерв. У опубликованных цен есть ссылки. Остальные суммы — расчётные. Междугородний перелёт в диапазон не входит.
- Видео: каталог содержит реальные экскурсии, прогулки, репортажи и съёмки с дрона конкретных мест. Раздел «Видео» показывает только карточки с привязанной съёмкой. В карточках остальных мест указан статус и есть ссылка для поиска по названию. Видео открываются с площадки автора. Для встроенного проигрывателя лучше запускать сайт через `node serve.mjs`, а при ограничениях площадки использовать кнопку «Открыть оригинал».
- Карта: [OpenStreetMap](https://www.openstreetmap.org/copyright). Прогноз: [Open-Meteo](https://open-meteo.com/). Избранное, язык и заметки сохраняются в браузере.
